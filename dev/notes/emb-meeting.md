# 2차 회의 — 추가 요청 2건
요청 A: "마스터 챌린저 좀 더 이쁘고 화려하게." / 요청 B: "롤 티어 오르듯이 단계적으로 촥촥촥 쌓이면서 문양 만들어지게 해 줘. 승급할 때!"

## 1. 1차 평가(요청 기준으로 다시 봄)
| 담당 | 점수 | 근거 |
|---|---|---|
| 비주얼 | 86 | 마스터·챌린저가 한 겹 날개+방패로 아래 티어와 격차가 작음. 보석·후광·광택 없음 |
| 모션 | 84 | 새 문양이 한 번에 커지며 나옴 → '쌓이는' 맛이 없음. 최상위 승급도 다른 티어와 같은 세기 |
| 접근성 | 95 | 기존 모달 접근성 유지. 다만 조립 연출이 길어지면 건너뛰기가 필요 |

## 2. 방향
- 마스터·챌린저는 emblem()에서 embTop()으로 분리(다른 티어 코드 그대로). 마스터=보라 날개 2겹+은 테두리+자수정, 챌린저=금 날개 3겹+보석 왕관+루비+빛줄기.
- 조립은 emblem(t,sz,true)일 때만 부품을 `<g data-st="n">`로 감쌈 → 평소 문양은 DOM 그대로(영향 없음). 축하 창 CSS가 data-st 순서대로 animation-delay.

## 3. 수정 내역
- 문양(embTop): 깃털을 한 장씩 계산해 겹겹이 쌓은 날개(EMB_F) + 깃털 결(30px↑) / 금속 테두리 방패 + 에나멜 + 면 나눈 가운데 보석 / 보석 박힌 테두리(30px↑ 2개, 46px↑ 7개) / 후광 광채(46px↑, 챌린저는 회전 빛줄기 추가) / 날개·방패·왕관 전체를 지나가는 광택 / 반짝임(마스터 2~4, 챌린저 4~6). 22·32px은 실루엣(보라 날개+자수정 장식 vs 금 날개+왕관)만 남겨 뭉개지지 않게.
- 빛줄기·광채 반지름을 viewBox 안에서 다 사라지게 줄여 네모난 경계 제거. 다른 티어 월계수·지느러미는 좌우 따로 끼워지게 분리(모양 변화 없음).
- 조립 단계 수: 브론즈 3 · 실버 4 · 골드 5 · 플래티넘 5 · 다이아 6 · 마스터 7 · 챌린저 8. 간격 0.18s(3단계)→0.13s(8단계).
- 순서: 바탕 방패 → 테두리(에나멜) → 가운데 표식/보석 → 날개·월계수 좌우(가운데에서 펼쳐짐) → 보석 테두리 → 왕관(위에서 떨어져 끼워짐)·후광 → 빛 번쩍·고리·입자 → 티어 문구.
- 박자: 부품마다 1.5배에서 0.93배로 튀었다 자리 잡는 이징 + 끼워질 때 2.5px 쿵 흔들림 + 작은 빛. 전체: 브론즈(배치) 0.91s, 골드 1.39s, 마스터 1.59s, 챌린저 1.66s에 마무리 → 입자까지 2.5초 안.
- 마스터·챌린저 승급: 입자 18→30개·더 멀리, 두 번째 고리, 촘촘한 빛줄기, 카드 둘레 광채, 문양 136px(PC 154px).
- 확인 버튼은 연출 중에도 보임: 1번 누르면 바로 완성, 다시 누르면 닫힘. Esc는 바로 닫힘. 움직임 줄이기: 조립 없이 완성 문양만, 확인 1번에 닫힘.
- 챌린저 축하 색을 금빛으로(EMB_P 챌린저 색만 변경, 축하 창에서만 쓰임). 고리가 시작 전에 미리 비치던 문제(tRing 0%) 수정.
