## 7. 상점 팀 코드가 합쳐질 때 붙이는 법(구체)

상점 팀 `eco.js`(ECO START~END)에 이미 있는 API: `ecoRewards()`, `ecoRewardCount()`, `ecoClaimAll()`, `ECO.auto`, `ecoMis()`, `ecoProgGet()`, `ecoDay()`, `ecoPaint()`.

1. **자동 받기 끄기**: `ECO.auto=true;` → `ECO.auto=false;` (과제·승급·업적 보상이 조건을 채우면 바로 들어가지 않고 띠에 '받을 보상'으로 모임)
2. **공급자 등록**(ECO 블록 끝, `ecoBoot` 뒤 아무 곳 — `rwAdd`는 FEAT END 위에 정의된 함수라 선언 순서 상관없음):
   ```js
   rwAdd({id:'eco',order:0,
    items:()=>{if(!ECO.ok||!ECO.w)return[];
     const R=ecoRewards().map(r=>({id:r.key,t:r.n,st:'ready',g:r.g}));
     const dq=ECO.w.d===ecoDay()?ECO.w.dq:[],v=ecoProgGet();
     const P=ecoMis().map((m,i)=>dq.includes('m'+i)||(v.p[m.id]|0)>=m.n?null:{id:'m'+i,t:m.t,st:'prog',p:`${Math.min(m.n,v.p[m.id]|0)}/${m.n}`}).filter(Boolean);
     return R.concat(P)},
    claim:()=>ecoClaimAll()});
   ```
3. **다시 그리기**: `ecoPaint()` 맨 끝(try 안)에 `try{rwPaint()}catch(e){}` 한 줄. 지갑을 읽은 뒤(`ecoAfterLoad`)·과제 진행(`ecoProg`) 뒤에도 ecoPaint가 불리므로 이것으로 충분.
4. **묘수 풀이 과제(`pz`)**: 문제를 풀면 띠의 `new`(풀기) 항목은 사라지고, 상점의 과제 보상이 `ready`(오늘의 묘수 풀이 · 구슬 10)로 들어와 [모두 받기]로 받음. 묘수 풀이 쪽 코드는 손댈 것 없음.
5. **시즌 보상**: `ecoRewards()`가 `k:'season'`을 주므로 띠에도 뜸. 결산 창(`#recap`)의 [받기](`ecosz`)는 그대로 둬도 됨(같은 키라 한 번만 받힘).
6. **홈 '꾸미기' 카드 `#ecoCard`**: 구슬 칩·교환소·보관함 버튼은 그대로. 과제 줄(`.eqline`)은 진행 보기용으로 남기고, '받기'는 띠 하나로(중복 버튼 만들지 않기).
7. **(나중) 출석체크·시즌 길**: 단계가 열려 받을 것이 생기면 같은 방식으로 `rwAdd({id:'stamp',order:5,items:()=>[{id:'st12',t:'시즌 길 12단계',st:'ready'}],claim:...})`.
8. 한도: 띠는 서버를 읽지 않음(공급자가 이미 가진 값만). 받기 쓰기는 상점 팀 `ecoClaimAll()`이 하던 그대로(과제 1번 + 1회성 보상마다 1번).
