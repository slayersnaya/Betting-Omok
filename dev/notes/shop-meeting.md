### 2-1. 지갑 `wal/{uid}` (본인만 읽고 씀, 지우기 금지)

| 칸 | 뜻 |
|---|---|
| g | 구슬(0~99,999) |
| d · dc · dq | 오늘 한국 날짜 번호(서버 시각과 같아야 함) · 오늘 받은 구슬(≤150) · 오늘 한 번씩 받은 것(`w` 첫 승, `m0~m2` 과제) |
| own · eq | 보유 꾸미기 · 장착 {t 칭호, n 닉네임 장식, f 테두리, s 인장, w 돌, b 판, x 완성 연출} |
| cl | 한 번만 받는 보상 키: `s{n}` 시즌 보상, `p{n}_{t}` 승급, `a_*` 업적 |
| k · at | 이번 쓰기 종류(new·earn·claim·buy·equip·reset) · 서버 시각 |

- plan.md의 `clm/` 문서+일괄쓰기 대신 **같은 문서 안 cl 목록**으로 1회성 보상을 막음 → 쓰기 1번, 어댑터(일괄쓰기) 수정 불필요. 지갑은 지우기 금지라 "지웠다 다시 만들어 또 받기"가 불가능. 계정 삭제 때는 비우기만(구슬·보유·장착 0, cl만 남김. 개인정보 없음).
- prof와 분리: profSave(닉네임·AI 전적)와 서로 간섭하지 않음.

### 2-2. 규칙(firestore.rules)이 지키는 것

| 쓰기 종류 | 검사 |
|---|---|
| earn | 늘어난 양 ≤ 15 + 첫 승 20 + 과제 10×개수, 하루 합계 150, 날짜가 바뀌면 0부터(서버 날짜), 보유·cl 그대로 |
| claim | cl에 새 키 하나만 추가 · 이미 있으면 거부 · 금액표와 정확히 같아야 함. 시즌 보상은 **관리자 기록 `cfg/season{n}`을 읽어** 내 최종 티어·랭크전 10판 이상·금액표(`amt`, 없으면 기본표)·테두리 아이템까지 대조. 승급 키는 지금 시즌 이하만(다음 시즌 미리 받기 거부). 계정 연결 업적은 실제 연결 계정만 |
| buy | 새 아이템 하나 · 규칙 안 가격표와 **정확히 같은 값만** 차감 · 티어 테두리 등 판매 목록 밖 거부 |
| equip | 구슬·보유·cl 그대로, 장착은 **보유한 것만·분류 맞게**(모든 쓰기 공통 검사) |
| reset | 구슬·보유·장착 0, cl 유지 |
| 공개 장착 eq | `res`·`bres`·`rt` 대국 접속·`on` 친구 접속에 실을 때 **내 지갑에 있는 것만**(바뀔 때만 지갑을 읽음 — 20초 '살아 있음'은 읽기 없음) |

- 관리자 폰의 시즌 마감 기록(seasonSnapTry)에 보상표 `amt:[200,400,700,1000,1400,1800,2500]`를 함께 남기도록 한 줄 추가 → 다음 시즌 시작 점수와 보상이 **같은 문서**로 정해짐(랭크팀 규칙이 이미 `amt` 칸 허용).

## 6. 수정

- 경제: `ecoRecap`이 지갑·시즌 기록 확인 뒤 보상 줄만 다시 그림(결산 창에서 바로 '받기'). 3턴 미만 0(`3턴 이상 둔 판부터…` 한 줄), 기권·시간 초과 3회·상대 부재로 진 판 0, 같은 상대 일반 게임 하루 5판 넘으면 0, 상한 도달 시 결과 줄에 이유.
- UX: 칭호 타일은 그림(닉네임+칭호)만, 물결 밑줄 두께·간격 조정으로 잘림 없앰, 안내 문구를 `구슬은 꾸미기에만 쓰여요 · 뽑기 없음` 한 줄 등으로 축소, 과제 이름 '오늘의 묘수 풀이'.
- 프론트: `ecoRewards / ecoRewardCount / ecoClaimAll / ECO.auto` 분리, 업적 조건 `ecoAchWant()` 분리. 지갑 오기 전에는 '불러오는 중', 쓰기는 한 줄로 세워 차례로, 규칙에 막히면 서버 지갑을 다시 읽고 한 번 더.
- 규칙: 하루 상한 경계 시험(151까지 채우는 위조) 추가, rt는 eq가 **바뀔 때만** 지갑을 읽게, 시즌 보상은 `cfg/season{n}`의 티어·판 수·금액표·테두리 아이템까지 대조(다른 티어·금액, 10판 미만 거부 시험).
- QA: 클릭 막힘 원인은 시험 코드가 가짜 대국 상태를 남겨 기존 클릭 처리기(vstate)가 멈춘 것 → 시험에서 정리 후 해결(앱 버그 아님). 글꼴 CDN 실패(네트워크 차단)는 콘솔 오류 집계에서 제외. 실제 규칙 엔진 시험 불가는 한계로 남기고 사용자 할 일에 적음.

## 9. 한계 · 2단계 목록

1. **실제 Firestore 규칙 엔진 시험 안 됨**(에뮬레이터 다운로드가 이 환경에서 막힘) → 배포 전 콘솔 플레이그라운드 확인.
2. 위조 한계: 하루 150, 1회성 키마다 1번까지(서버 없이 막을 수 없음). 2단계(Blaze + Cloud Functions)에서 대국 결과 검증 뒤 지급.
3. 출석체크·시즌 길(40단계)·주간 과제 → 2단계(지갑에 칸 추가 방식).
4. 랭킹 줄 꾸미기는 **새 랭크 결과가 쌓여야** 보임 — 지금 랭크전 점검 중(RANK_MAINT)이라 랭킹 표시는 점검이 끝난 뒤부터. 대국 상단 바·친구·프로필은 지금도 보임.

6. 폰 시계가 크게 틀리면(자정 근처) 날짜 검사에 막힐 수 있음 → 서버 지갑을 다시 읽고 한 번 더 시도.
7. 상품을 늘릴 때는 **규칙 가격표(ecoPrice)와 앱 목록(ECO_ITEMS)을 함께** 고쳐야 함.
8. 유료 상품: `ECO_PAID` 칸과 화면 자리만. 결제·광고·서버 권리(ent/{uid})는 앱 출시 때.
