# 플레이 스토어 등록 문구 (초안)

## 앱 이름
베팅 오목

## 짧은 설명 (80자 이내)
세 칸을 고르고 점수를 몰래 걸어 돌을 놓는 2인 전략 오목

## 자세한 설명
베팅 오목은 오목에 '눈치 싸움'을 더한 2인 전략 게임입니다.

■ 이렇게 둬요
- 매 턴 선 플레이어가 이어진 빈칸 세 개를 고릅니다.
- 두 사람이 칸마다 점수를 몰래 걸어 봉인합니다.
- 더 많이 건 사람이 그 칸에 돌을 놓습니다. 같으면 후 플레이어 돌.
- 먼저 오목(정확히 5개)을 만들면 이깁니다.

■ 이런 재미
- 상대의 남은 점수를 읽고, 꼭 필요한 칸에만 크게 거는 수 싸움
- 친구 대국(방 코드·초대 링크), 랭크전(티어·시즌), AI 대국(초보·중수·고수·Ultimate)
- 끝난 뒤 복기에서 두 사람의 베팅을 모두 확인

■ 안내
- 게임 안 점수는 돈이나 상품으로 바꿀 수 없고, 결제 기능이 없습니다.
- 개인정보처리방침: https://slayersnaya.github.io/Betting-Omok/privacy.html

## 콘텐츠 등급 설문 답변 방향
- 폭력·성적 내용·욕설: 없음
- 도박: '실제 돈을 걸거나 얻는 기능 없음', '모의 도박(카지노 게임) 아님' — 점수 입찰은 게임 규칙의 일부이고 현금·아이템 교환 없음
- 사용자 간 소통: 닉네임만 공개(채팅 없음)
- 위치 공유·개인정보 공유: 없음
